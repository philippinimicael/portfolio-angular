# Sistema de Autenticação Angular

## Sobre
Sistema de login e cadastro desenvolvido para estudo de Angular.

## Funcionalidades
- Cadastro de usuários
- Login
- Persistência com LocalStorage
- Validação de formulários

## Tecnologias
- Angular 22
- TypeScript
- Reactive Forms

## Como executar
npm install
ng serve
